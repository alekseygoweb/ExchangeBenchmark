# ExchangeBenchmark

Замер задержки торговых операций на **Binance** и **OKX** (фьючерсы и спот),
по двум транспортам — REST API и WebSocket.

- `latency_test.py` — цикл «разместить лимитный ордер → отменить ордер»,
  считает задержку размещения, отмены и суммы (мс).
- `socket_test.py` — отдельный замер времени открытия WebSocket-сокета
  (DNS + TCP + TLS + upgrade) и логина OKX.

> ⚠️ **Скрипт работает на БОЕВЫХ счетах (PROD, РЕАЛЬНЫЕ ДЕНЬГИ).**
> Размещаются настоящие лимитные ордера и сразу отменяются. Они должны стоять
> далеко от рынка (non-marketable), чтобы не исполниться. Весь риск на вас.

## Установка

```bash
pip install -r requirements.txt
```

## Ключи API (.env)

Ключи **не хранятся в конфигах** и не коммитятся в git. Они берутся из
переменных окружения, которые удобно держать в файле `.env`.

1. Скопируйте образец и заполните своими боевыми ключами:

   ```bash
   cp .env.example .env
   ```

2. Заполните в `.env`:

   ```dotenv
   BINANCE_API_KEY=...
   BINANCE_API_SECRET=...

   OKX_API_KEY=...
   OKX_API_SECRET=...
   OKX_API_PASSPHRASE=...
   ```

`.env` подхватывается автоматически (через `python-dotenv`, а если пакет не
установлен — встроенным мини-парсером). Реальные переменные окружения имеют
приоритет над значениями из `.env`, так что в CI ключи можно передавать
напрямую через окружение, не создавая файл.

Для Binance можно задать отдельные ключи под фьючерсы и спот
(`BINANCE_FUTURES_API_KEY` / `BINANCE_SPOT_API_KEY` и соответствующие секреты) —
они переопределяют общий `BINANCE_API_KEY`.

## Запуск

```bash
python latency_test.py        # спросит подтверждение (реальные деньги)
python latency_test.py --yes  # без подтверждения (например, для автоматизации)
python socket_test.py
```

## Конфиги (без секретов)

Торговые параметры лежат в `config_binance_PROD.json` и `config_okx_PROD.json`
(символ, сторона, цена, объём, URL-ы). Путь можно переопределить переменными
`CONFIG_BINANCE` / `CONFIG_OKX`.

### ⚠️ Важно про цену ордера

Биржи отклоняют лимитные ордера, стоящие слишком далеко от текущей цены
(price-band фильтры: Binance `PERCENT_PRICE_BY_SIDE`, OKX лимит цены). Заглушка
`"price": "20000"` для BTC на боевом рынке, скорее всего, будет **отклонена**.

Есть два варианта:

1. **Авто-цена (рекомендуется)** — пусть скрипт сам посчитает безопасную цену
   от текущего рынка (см. ниже). Тогда поле `price` в конфиге не используется.
2. **Вручную** — выставьте в конфигах цену в допустимом коридоре, но заведомо
   неисполняемую (например, BUY на несколько процентов ниже лучшего бида).

В любом случае проверьте, что объём проходит минимальный номинал биржи.

### Авто-цена (опционально)

Скрипт может сам подобрать **безопасную неисполняемую** цену: берёт текущие
лучшие бид/аск, отступает на `PRICE_OFFSET` процентов в «безопасную» сторону
(для BUY — ниже бида, для SELL — выше аска) и округляет к шагу цены инструмента
(`tickSize`). Цена заведомо не пересекает спред (ордер не исполнится) и при этом
попадает в ценовой коридор биржи. Запросы цены делаются **до** таймера и на
замер задержки не влияют.

Включение (любой из способов):

```bash
python latency_test.py --auto-price --yes          # флаг командной строки
AUTO_PRICE=1 python latency_test.py --yes           # переменная окружения
```

или в конфиге (общий ключ или внутри блока рынка):

```json
{ "auto_price": true, "price_offset_pct": 1.0, "futures": { ... } }
```

Отступ задаётся через `PRICE_OFFSET` (проценты, по умолчанию `1.0`) или
`price_offset_pct` в конфиге. Перед таблицей печатается посчитанная цена:

```
  [auto-price] Binance futures: 99000.0
  [auto-price] OKX spot: 99123.4
```

## Переменные окружения (сводка)

| Переменная | Назначение |
|---|---|
| `BINANCE_API_KEY`, `BINANCE_API_SECRET` | Ключи Binance (общие для спота/фьючерсов) |
| `BINANCE_FUTURES_*`, `BINANCE_SPOT_*` | Необязательные ключи под конкретный рынок |
| `OKX_API_KEY`, `OKX_API_SECRET`, `OKX_API_PASSPHRASE` | Ключи OKX |
| `CONFIG_BINANCE`, `CONFIG_OKX` | Пути к конфигам |
| `LATENCY_REPEATS` | Число повторов цикла (по умолчанию 5) |
| `LATENCY_CONFIRM` | `1`/`yes` — пропустить подтверждение |
| `AUTO_PRICE` | `1`/`yes` — авто-цена от рынка (= флаг `--auto-price`) |
| `PRICE_OFFSET` | Отступ авто-цены от бида/аска в процентах (по умолчанию 1.0) |
